Drop in any self-contained HTML document (a Switch white paper or deck, a client report, anything built as a single file).

  • It appears exactly as it will in the PDF.
  • Click any text and type. Select a whole sentence to rewrite it, or delete a paragraph outright. Fonts, colours, layout and logos cannot be changed.
  • Find and replace (⌘F) changes a name or a date everywhere at once.
  • Select anything you'd rather Claude handled and press Comment (⌘K).
  • Press ⌘S. Your edits and comments save into the same file — and the Review panel lists every change before you do.

“Copy brief for Claude” saves and copies a request to paste to Claude. Leave this tab open while Claude works: when it changes the file, the page updates by itself — keeping any unsaved edits — and each comment shows Claude's reply.
